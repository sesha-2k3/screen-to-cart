# Project structure and naming

```
screen-to-cart/
├── extension/                 # WXT + React + TS
│   ├── entrypoints/
│   │   ├── content/index.ts   # pause/seek, draws frames from the <video> element, ad check
│   │   ├── player.content.ts  # MAIN world: player data, caption responses, transcript
│   │   ├── background.ts      # hotkey, /lookup, capture flow, messaging
│   │   └── sidepanel/         # React app
│   ├── lib/api.ts             # openapi-fetch client + fetch-event-source for SSE
│   └── lib/api-types.ts       # GENERATED by openapi-typescript, never edit by hand
├── backend/
│   ├── app/
│   │   ├── main.py            # /lookup (cache), /identify (SSE), /health
│   │   ├── config.py          # pydantic-settings; model names per role
│   │   ├── observability.py   # Langfuse setup
│   │   ├── llm/               # get_llm(role), rate limiter, record/replay
│   │   ├── graph/             # state.py, nodes/, build.py
│   │   ├── retailers/         # base.py (Listing, search interface), ebay.py, bestbuy.py
│   │   ├── vision/            # frame_select.py, siglip.py
│   │   ├── db/                # models, Alembic migrations, pgvector
│   │   └── schemas.py         # Pydantic models
│   ├── eval/                  # labels.jsonl, runner, metrics, reports
│   └── tests/
├── fixtures/                  # recorded LLM + retailer responses for replay mode
├── docs/                      # build plan and guides
└── docker-compose.yml
```

## Naming
- Product name: "Screen to Cart". Repo/folders: `screen-to-cart`. Python project: `screen-to-cart-backend`. Extension package: `screen-to-cart-extension`. Database: `screen_to_cart`.
- Python: snake_case modules and functions, PascalCase classes. One LangGraph node per file in `graph/nodes/`.
- TypeScript: camelCase functions, PascalCase React components, one component per file.

## Where new code goes
- A new retailer → `backend/app/retailers/<name>.py` implementing the base interface, plus tests with mocked HTTP (`respx`).
- A new pipeline step → a node file in `graph/nodes/`, wired in `graph/build.py`, with its state fields in `graph/state.py`.
- A new API payload → a Pydantic model in `schemas.py`, then regenerate `extension/lib/api-types.ts`.
